# הבדיקות

```
npm test            # הכל — בדיקות יחידה + ביקורות האימונים + רינדור
npm run test:unit   # רק בדיקות היחידה (vitest)
npm run test:app    # רק ביקורות האימונים והרינדור
```

הרצה ראשונה דורשת דפדפן: `npx playwright install chromium`.

## למה זה בנוי ככה

**הבדיקות קוראות את `app.js` עצמו.** קודם היה כאן `src/pure.js` — עותק של
הפונקציות שאף אחד באפליקציה לא ייבא. הוא נשאר מאחור: באוקטובר הוא עדיין אישר
את יעד הקלוריות הקפוא ואת החלבון הקבוע ש-`app.js` הפסיק לעשות בספטמבר, כך
ש-43 בדיקות ירוקות העידו על באג. `from-app.mjs` חותך את הפונקציה מהמקור ומריץ
אותה — אין עותק שני שיכול להתיישן.

**מה שלא ניתן לתיקון מסומן בשמו.** תוכנית משקל גוף לא יכולה להגיע לסף הגדילה
בכתף אמצעית — אין הרמות צד בלי ציוד. במקום להרפות את הסף או להשאיר את החבילה
אדומה לנצח, החריגה רשומה בשמה המדויק, והבדיקה עדיין נופלת על כל דבר אחר באותה
תוכנית. אותו דבר לחפיפה בין ימי הבית, שהיא עבודה פתוחה ולא רגרסיה.

## הקבצים

| | |
|---|---|
| `run.mjs` | מריץ הכל ומסכם |
| `from-app.mjs` | חותך פונקציות מ-`app.js` |
| `catalogue.mjs` | קורא את `EX` ו-`WORKOUT_PLANS`, והגדרות משותפות |
| `pure.test.js` | חישוב תזונה, פענוח סטים ומנוחה |
| `audit_order.mjs` | סדר התרגילים בכל יום |
| `audit_plans.mjs` | נפח שבועי, כפילויות, ימי א׳ מול ב׳, שלמות |
| `probe_smoke.mjs` | כל תוכנית מרנדרת, כל חלון תרגיל שלם |
| `serve.mjs` / `pw.mjs` | שרת סטטי ודפדפן |

## אחרי שינוי בתוכניות אימון

`npm test` חייב לעבור. בפרט: אפס ממצאי סדר, אף שריר מחוץ ל-MEV/MRV, ואף תרגיל
שחוזר פעמיים באותו אימון.

**כשכלל מסמן יותר מדי — לבדוק את הכלל לפני שמתקנים את הקוד.** שני כללי סדר
נמחקו אחרי שסימנו תכנון תקין: «שריר מפוזר» סימן כתפיים בעמדות 2, 5 ו-6 ביום
דחיפה, שזה הסדר הנכון, ו«שני כבדים ברצף» סימן סקוואט ואז לחיצת חזה, שלא
מתחרים על כלום. שניהם יחד ייצרו 39 מתוך 51 ההתראות.
